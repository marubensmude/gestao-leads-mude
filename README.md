# Gestão de Leads · Mude Imóveis

Plataforma interna de follow-up de atendimentos da Mude Imóveis (Dourados-MS).

Acesso em: https://marubensmude.github.io/gestao-leads-mude/

Os dados são criptografados (AES-256-GCM, chave derivada por PBKDF2) e só podem ser abertos com a senha individual de cada corretor. Nenhuma informação de cliente é armazenada em texto legível neste repositório.
